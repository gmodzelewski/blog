# MySQL Database as Model Registry on OpenShift AI

According to the [official documentation](https://docs.redhat.com/en/documentation/red_hat_openshift_ai_cloud_service/1/html/managing_model_registries/creating-a-model-registry_managing-model-registries), when using MySQL as a model registry on OpenShift AI, it is important to ensure that the `mysql_native_password` authentication plugin is enabled. This is required for the ML Metadata component to successfully connect to your database.

If you need to change the authentication plugin, you can follow the instructions provided in the [MySQL documentation](https://dev.mysql.com/doc/refman/8.4/en/native-pluggable-authentication.html). After making this change, if you encounter issues connecting, try logging in once with your user credentials using the MySQL CLI. This often resolves any remaining authentication problems.

# Java Upgrade and Modernization Program (JUMP)

You may have heard about the [Java Upgrade and Modernization Program (JUMP)](http://red.ht/jump), especially in the context of customers seeking discounts for Extended Lifecycle Support (ELS) Java subscriptions. 

It is important to note that JUMP is not a discount program. Instead, it is an investment program where the cost is equivalent to ELS, but the funds are used to engage consultants who will help migrate your software to the latest Java versions. This means you get expert assistance with modernization, rather than just an extension of support.
