### Red Hat Kafka Q&A

Recently I attended a meeting with a customer about Red Hat Kafka and some deeper questions came up which I answered and would like to share. Here in short form:

- *Is there a recommended was/tooling to visualize topics?*
  - Console can be additionally installed
  - creates a private prometheus instance to scrape metrics
  - [Install via new Operator: Red Hat Streams for Apache Kafka Console](https://docs.redhat.com/en/documentation/red_hat_streams_for_apache_kafka/2.8/html/using_the_streams_for_apache_kafka_console/assembly-deploying-str#proc-deploying-operator-olm-ui-str)
- *What is the recommended way for scaling/rebalancing?*
  - [For rebalancing: Use Cruise Control](https://docs.redhat.com/en/documentation/red_hat_streams_for_apache_kafka/2.8/html/deploying_and_managing_streams_for_apache_kafka_on_openshift/cruise-control-concepts-str#cruise-control-concepts-str)
  - [finer granular config via KafkaRebalance CR](https://docs.redhat.com/en/documentation/red_hat_streams_for_apache_kafka/2.8/html/deploying_and_managing_streams_for_apache_kafka_on_openshift/cruise-control-concepts-str#con-optimization-proposals-modes-str)
  - [Scale kafka brokers via setting the replicas in the CR](https://docs.redhat.com/en/documentation/red_hat_streams_for_apache_kafka/2.8/html/deploying_and_managing_streams_for_apache_kafka_on_openshift/con-scaling-kafka-clusters-str)
- *What is the best way to deploy on multiple clusters via GitOps?*
  - Use the ApplicationSet object with git generators instead of AppOfApps pattern
  - You can reference external git repositories containing the values (better separation of concern)
  - Free ebooks from Red Hat describe how to do it:
    - [The Path to GitOps - Chapter 4 Git workflows](https://developers.redhat.com/e-books/path-gitops)
    - [GitOps Cookbook - Chapter 8.4 Advanced Topics - Deploy to multiple clusters](https://developers.redhat.com/e-books/gitops-cookbook)
    - [Another example](https://github.com/gmodzelewski/quinoa-wind-turbine-manifests/blob/main/wind-turbine-app.yaml)
- Storage considerations
  - Block storage (Amazon EBS volumes, Azure Disk Storage, Google Cloud Persistent Disk, onPrem local persistent volumes)
  - Specify persistent-claim in the storage configuration of the Kafka resources. 
  - [Link to documentation](https://docs.redhat.com/en/documentation/red_hat_streams_for_apache_kafka/2.8/html/deploying_and_managing_streams_for_apache_kafka_on_openshift/overview-str#considerations-for-data-storage-str)
